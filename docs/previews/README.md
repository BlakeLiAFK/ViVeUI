The workflow's `ViVeUI-native-validation` artifact contains all 128 multilingual
renders (eight per language), plus ten regression renders. Standard viewports
are 1440×900 and 900×900; the 150% raster fixture uses 960×800 logical pixels.
These are offscreen control-tree renders, not physical desktop captures or
screenshots of Windows experimental features. Translation accuracy and complex
script shaping still require native-speaker review.

The same run passed 74 core tests, resource/wiring audit, language persistence,
state preservation, RTL direction, key action visibility, installed glyph checks,
localized safe-default confirmations, cross-integrity authenticated IPC,
x64/ARM64 single-EXE builds, and clean-folder x64 launch.
